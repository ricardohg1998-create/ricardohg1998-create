# Hi, I'm Ricardo Huertas

I build web applications, CRMs and automations. My background in marketing and commercial operations helps me understand the work behind the software: how a lead gets assigned, what an agent needs on screen, or what happens when an integration fails.

My work includes a commercial platform with browser-based telephony, a property valuation product, and a CRM that can be operated through both a web interface and MCP tools.
